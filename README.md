# Bright Path

Bright Path is a static website for a school coaching centre. It introduces the centre, its values and faculty, the courses on offer, a photo gallery, student questions, and ways to get in touch.

Open `index.html` in a browser to view the site. There is no build step.

## Pages

| Page | File | What it shows |
| --- | --- | --- |
| Home | `index.html` | Welcome slider, academic test details, courses, videos, faculty preview, and a map |
| About Our Coaching | `AboutCoachingC.html` | How Bright Path teaches, plus a demo registration form |
| Our Values | `our_values.html` | Courage, responsibility, empowerment, and continuous self renewal |
| Our Team | `our_team.html` | Faculty profiles |
| Secondary School | `course_secoundary.html` | Secondary course outline, including recorded lectures, e-books, and assignments |
| Higher Secondary | `higher_secoundary.html` | Class XI–XII Maths and Science programme |
| Other Courses | `othercourse.html` | Additional course information |
| Gallery | `gallery.html` | Photo gallery |
| FAQ | `FAQ.html` | Common questions about joining Bright Path |
| Contact Us | `contact_us.html` | Map, centre address, phone, email, alternative contact, and a feedback form |

Every page shares the same navigation and footer. The footer lists why to choose Bright Path, courses from Class VI to Class XII and IELTS, contact details, and the student zone.
